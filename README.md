# CALLORIA v7.25 — Digital Follow-up Coaching

This release adds a supervisor-owned coaching workflow to the digital follow-up response scorecards introduced in v7.24.

The Supervisor workspace now displays coaching recommendations backed by overdue follow-ups, at-risk open work or sustained response-target performance below 85% across at least three completed cycles. Supervisors can create a plan, start it and mark it completed. Active plans suppress duplicate recommendations for the same agent.

The feature uses synthetic local game state only. It does not make disciplinary or employment decisions and does not connect to live customer channels.

See `INSTALL-GITHUB-v7.25.md` for the GUI merge steps and `CHANGELOG-v7.25.md` for scope and limitations.
