# CALLORIA v7.23 — Customer 360 Recovery Plan

A read-only recovery-priority and next-best-action layer for the existing shared Customer 360 panel.

The plan surfaces repeat-contact, open-case, cross-channel, low-QA and low-sentiment signals so an agent can continue the existing customer journey rather than make the customer repeat everything or create a duplicate case.

See `INSTALL-GITHUB-v7.23.md` for GUI installation steps and the required single Vite plugin registration.
