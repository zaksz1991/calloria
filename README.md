# CALLORIA v6.34 — Staff Facial Expression Morphs

This is an incremental replacement patch for the CALLORIA staff GLB build plugin. It adds subtle idle facial expressions for static staff models when their GLB files already contain supported smile/dimple or brow-raise morph targets.

No new packages, runtime pages, assets, API keys, Supabase changes, or database migrations are included.

See `INSTALL-GITHUB.md` before applying. This patch is intended to be applied on top of v6.33.
