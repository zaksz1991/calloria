# CALLORIA v7.11 — After-contact Evidence Quality Gate

This additive overlay makes inbound and outbound after-contact records more useful for training and operational review. It requires issue category, primary root cause, actual action, customer understanding and a factual-notes acknowledgement, then attaches the structured evidence to existing case records.

Read `INSTALL-GITHUB-v7.11.md` before merging. This is not a complete repository replacement and does not include the application's existing source tree or assets.
