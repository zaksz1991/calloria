# Changelog — v6.51

- Removed Finacle from the simulated enterprise systems registry; the optional banking support examples remain separate from the general customer-experience default.
- Added RuffNeck LMS, Prospector, Connect, Social Hub, Kano Run and Kano Keke to the Workforce service directory.
- Added platform-specific customer request types, self-service routes, agent workflows, escalation triggers and consent-led cross-service guidance.
- Added one scored customer-support practice scenario for each of the six RuffNeck services. Attempts are saved as separate practice records through the existing application save pathway and do not affect QA, KPIs, salary, XP or promotion eligibility.
- Changed clean/new applicant defaults from Banking Operations to General Customer Experience; only empty legacy applicant profiles are migrated. Existing submitted applications and existing selected tracks are preserved.
- Existing Finacle event history is hidden from the system activity panel; it is not deleted from older local saves.
