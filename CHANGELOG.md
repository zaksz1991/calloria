# Changelog

## v6.48 — Career Competency Passport

- Added a competency passport to the existing employee Career profile.
- Maps human-QA coaching criteria into seven practical customer-operations competency areas.
- Counts only currently verified plans whose last human follow-up outcome is `improved`.
- Displays active plans, verified evidence, guided-practice attempts and latest review references separately.
- Keeps guided practice formative; it cannot qualify an employee as competent by itself.
- Does not modify XP, salary, operational KPIs, promotion eligibility or annual examination rules.
- Registered v6.48 after v6.47 in the replacement `vite.config.js`.
- Carries the required v6.42–v6.47 plugins and focused tests for cumulative installation.
