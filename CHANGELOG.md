# Changelog

## v5.8.0 — Billing & Revenue Operations

- Added order register, order approval, recurring order lifecycle controls and one-way import of won v5.7 sales opportunities.
- Added draft and issued invoice lifecycle, recurring period uniqueness, due-date controls, invoice locking and void restrictions.
- Added evidence-backed receipt recording with external reference de-duplication and independent recorder/verifier separation.
- Added customer/currency-matched receipt allocation and over-allocation/overpayment prevention.
- Added maker-checker credit notes with balance revalidation and invoice balance application.
- Added invoice disputes, dispute resolution and pause on collection task creation while a dispute remains open.
- Added internal collection task register without external customer messaging.
- Added refund request, independent approval and separate settlement recording against a selected payment/invoice allocation; settled refunds reverse that allocation in the local ledger.
- Added multi-currency summaries without FX conversion, receivable aging, control queue and protected CSV exports.
- Added responsive page and focused engine/UI contract tests.
