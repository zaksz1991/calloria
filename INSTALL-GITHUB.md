# Installation — v6.51

1. Extract this ZIP.
2. In the GitHub repository, upload/merge the included `build/` and `tests/` folders, preserving existing files.
3. Replace the repository `vite.config.js` with the included cumulative version.
4. Commit the merged files to `main` and allow the existing Vercel deployment to run.

Do not replace package files, public models, Supabase credentials, environment variables or unrelated application pages.
