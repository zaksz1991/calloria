# Installation — CALLORIA v2.6

1. Extract the ZIP.
2. Open the extracted `.github/workflows` folder.
3. Add `calloria-production-gate.yml` to the same path in the CALLORIA repository.
4. Commit it to `main`.

No application files are replaced. The workflow starts automatically on the push and reports syntax, regression, production-build, and GLB-copy results in GitHub Actions.
